# ConstructPro - Construction Company Website

A modern, responsive website for ConstructPro construction company built with HTML, CSS, and JavaScript.

## 🌟 Features

- **Responsive Design** - Fully mobile-friendly and works on all screen sizes
- **Modern UI** - Clean, professional green-themed design
- **Interactive Navigation** - Smooth scrolling and active link highlighting
- **Mobile Menu** - Hamburger menu for easy navigation on smaller screens
- **Service Cards** - Showcase your services with beautiful card layout
- **Call-to-Action Button** - Engage visitors with prominent CTA buttons
- **Fade-in Animations** - Smooth animations as users scroll through the page
- **Professional Footer** - Complete footer with links and copyright information

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/iliyansky-bg/new-Repo1.git
cd "Construction web site"
```

2. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (http-server)
npx http-server
```

3. Visit `http://localhost:8000` in your browser

## 💻 Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with Flexbox and Grid

## 🔧 JavaScript Features

- **Mobile Menu Toggle** - Opens/closes navigation on small screens
- **Smooth Scrolling** - Smooth page navigation when clicking links
- **Active Link Highlighting** - Shows current section in navigation
- **Scroll Animations** - Fade-in effects for sections
- **Email Validation** - Built-in validation function

## 📱 Responsive Breakpoints

- **Desktop**: Full layout with side-by-side navigation
- **Tablet/Mobile** (max-width: 768px): 
  - Hamburger menu toggle
  - Stacked navigation
  - Single-column service cards

## 🎯 Usage Tips

1. **Customize Colors** - Edit the color variables in `style.css`
2. **Add Content** - Update section text in `index.html`
3. **Modify Services** - Add/remove service cards by duplicating `.service-card` divs
4. **Add Images** - Insert image tags in sections (add your own images)
5. **Update Links** - Modify footer links and navigation as needed
